# Guide Generator

Claude Code skill for generating project-level technical guide documents. Produces a single `guide.html` with sidebar TOC, syntax-highlighted code, dark/light theme toggle, and print optimization.

## Quick Start

```bash
git submodule add https://github.com/GeziP/guide-generator.git .claude/skills/guide-generator
```

No additional setup required. The skill auto-loads on session start.

## Usage

```
> 生成指导文档
> 给这个项目写个guide
> generate project guide
```

## What It Does

1. **Project Analysis** — scans directory structure, reads key source files (at least 5), identifies project type
2. **Structure Design** — selects chapter combination based on project type (embedded / web / CLI / library)
3. **Content Generation** — fills HTML template with architecture diagrams, flow charts, code blocks, tables, FAQ
4. **Quality Check** — verifies architecture diagrams, code references, business logic explanations, FAQ coverage

## Output Features

| Feature | Description |
|---------|-------------|
| Sidebar TOC | Auto-generated from H2/H3 headings, with ScrollSpy |
| Theme Toggle | Dark/light switch with localStorage persistence + OS preference detection |
| Code Highlighting | highlight.js CDN with auto-detection; fallback to manual spans |
| Code Copy | One-click copy button on every code block and ASCII diagram |
| Collapsible Sections | `<details>` blocks for FAQ, appendix, and reference sections |
| Tabs | Pure CSS tabs for comparing code/configs (up to 5 tabs) |
| Layer Stack | Visual architecture layers for system diagrams |
| Step Indicators | Numbered step cards for multi-phase workflows |
| Card Grids | Accent-colored cards with 6 color variants |
| Responsive | Sidebar drawer on mobile (900px breakpoint) |
| Print Optimized | Hidden nav, expanded folds, inline link URLs |

## How It Differs from deepwiki

| Scenario | Use |
|----------|-----|
| "What does this project do? How to get started?" | **guide-generator** |
| "Write API docs for Task class" | deepwiki-module |
| "Analyze the whole repo architecture" | deepwiki-system |

guide-generator focuses on **business logic understanding** (why things work this way, how to troubleshoot), while deepwiki focuses on **code structure extraction** (API references, module relationships).

## File Structure

```
guide-generator/
├── SKILL.md                 # Skill entry point (triggers + instructions)
├── README.md                # This file
└── template-guide.html      # HTML template (CSS + JS + placeholders)
```

## Template Placeholders

| Placeholder | Description |
|-------------|-------------|
| `{{PROJECT_NAME}}` | Project name (Hero, Topbar, Footer) |
| `{{PROJECT_DESC}}` | One-line description (Hero) |
| `{{PROJECT_META}}` | Tech stack metadata (Hero, Footer) |
| `{{SECTIONS}}` | All section content |

Sidebar TOC is auto-generated by JavaScript from H2/H3 headings — no manual nav links needed.

## Dependencies

- **CSS**: Fully inline (zero external CSS dependencies)
- **JS**: highlight.js 11.9.0 CDN for code highlighting (graceful fallback without network)
- **Offline**: Works without internet; code blocks fall back to manual `.cmt`/`.kw`/`.fn`/`.str`/`.num` spans
